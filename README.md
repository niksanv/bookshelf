# BookShelf

Консольный менеджер личной библиотеки на Java 17. Данные хранятся в памяти процесса и сбрасываются при завершении приложения.

## Возможности

- добавление, просмотр, редактирование и удаление книг;
- поиск по названию, автору и жанру (частичное совпадение, без учёта регистра);
- сортировка по названию, автору и году публикации;
- статус прочтения книги;
- проверка пользовательского ввода и понятные сообщения об ошибках.

## Архитектура

- `model` — `Book`, `BookInput` и перечисления предметной области;
- `repository` — интерфейс хранилища и in-memory реализация;
- `service` — бизнес-логика каталога;
- `validation` — единая точка проверки входных данных;
- `exception` — исключения приложения;
- `ui` — консольный ввод, меню и вывод;
- `Main` — сборка зависимостей и запуск приложения.

## Требования

- JDK 17 или новее;
- Maven 3.8+.

## Запуск

Из корня проекта выполните:

```bash
mvn clean package
java -cp target/classes ru.bookshelf.Main
```

Также можно запустить приложение из IDE, указав `ru.bookshelf.Main` как главный класс.

## Тесты

Тесты находятся в `src/test/java` и используют JUnit Jupiter:

```bash
mvn test
```
